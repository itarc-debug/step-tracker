# Step Tracker Pro

ระบบบันทึกและติดตามจำนวนก้าวการเดิน

## ✨ ฟีเจอร์

✅ User Panel - บันทึกการเดิน  
✅ Admin Panel - จัดการผู้ใช้  
✅ Export Excel - ดึงรายงาน  
✅ Real-time สถิติ  
✅ Share Link สำหรับ Group  

## 🚀 วิธีใช้

- **User:** เข้า `index.html?group=yourgroup`
- **Admin:** กดปุ่ม Admin Panel → รหัส: `9999`

## 📦 สถาปัตยกรรม

- Firebase Firestore - Database
- Firebase Storage - Image Storage
- Chart.js - Visualization
- XLSX - Excel Export
- Tailwind CSS - UI Design
